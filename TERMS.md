# Terms and Conditions

**Effective date:** 2026-05-15

## About

This application (`idiom-app`) is a personal, single-recipient SMS
notification tool that delivers one Spanish-language idiom and one
colloquialism per day to the owner's own phone number. The sole end
user is the developer/owner of the application.

## Service description

By configuring your own phone number as the destination in the
application's environment configuration (`TWILIO_TO_NUMBER`), you
consent to receive approximately **one (1) SMS message per day**
containing Spanish-language phrases for personal language-learning use.

## Message and data rates

Standard message and data rates may apply.

## Opt-out

Reply `STOP` to the application's Twilio number at any time to
unsubscribe from messages. Reply `HELP` for help.
